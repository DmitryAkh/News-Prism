# News Prism 💎

Приложение для поиска и подписки на интересующие темы новостей на основе API. Реализован выбор языка, частоты автоматических обновлений, а также уведомления о получении свежих статей.

## Функциональность

- Поиск и загрузка статей через API newsApi
- Фильтрация новостей по темам и языку
- Обновление в фоне с заданным интервалом и типом сети
- Получение уведомлений о свежих новостях
- Шэринг

## Стек

- Kotlin
- MVM
- Jetpack Compose
- Flow
- Coroutines
- Hilt
- Data Store
- BroadcastReceiver
- NotificationManager
- Serialization
